# New Year's Resolutions Social Media Analysis

## Project Overview

This project analyzes 4,723 social media posts about New Year's resolutions from 27 December 2014 to 2 January 2015.

The objective was to identify patterns in resolution categories, popular topics, geographic distribution, gender, and engagement.

## Tools Used

- Microsoft Excel
- PivotTables
- Data Cleaning
- Data Analysis
- Data Visualization

## Analysis

The analysis examined:

- Resolution categories
- Top resolution topics
- State and regional distribution
- Gender distribution
- Retweet engagement

## Key Findings

- Personal Growth was the largest resolution category, accounting for 1,678 tweets (35.53%).
- Philanthropic resolutions were the least represented, with 83 tweets (1.76%).
- The South had the highest number of tweets among the four regions, with 1,539 tweets.
- California had the highest number of tweets among individual states, with 701.
- Gender distribution was nearly equal, with 2,367 female tweets and 2,356 male tweets.
- Among tweets with recorded retweet counts, Finance had the highest average at 65.26 retweets per tweet.
